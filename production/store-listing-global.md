## 5. Build, Verification & Publishing Workflow

```bash
# 1. Chạy toàn bộ chu trình kiểm thử QA và Typecheck
npm run verify

# 2. Đồng bộ mã nguồn Web (Three.js 3D Arena + Logic) sang Native iOS & Android
npm run mobile:sync

# 3. Mở Xcode trên macOS để cấu hình Signing & TestFlight upload
npm run mobile:ios

# 4. Mở Android Studio để build Android App Bundle (.aab) cho Google Play Console
npm run mobile:android
```
